# Eco Cozy Childhood

Shopify store for eco-friendly children's products.

## Project Overview

This repository contains the source code for the Eco Cozy Childhood Shopify store.

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn
- Shopify CLI

### Installation

```bash
npm install
# or
yarn install
```

### Development

```bash
npm run dev
# or
yarn dev
```

### Build

```bash
npm run build
# or
yarn build
```

## Deployment

Push changes to the `main` branch to trigger automatic deployment.
