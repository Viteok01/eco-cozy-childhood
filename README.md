# Eco Cozy Childhood - Shopify Theme

This branch contains the Shopify theme files synced from Shopify Admin.

## Theme Structure

- `config/` - Theme configuration
- `layout/` - Theme layouts
- `sections/` - Reusable sections
- `snippets/` - Code snippets
- `templates/` - Page templates
- `assets/` - CSS, JS, images
- `locales/` - Translation files

For development and configuration, see the `develop` branch.
